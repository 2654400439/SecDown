# RQ3 Analysis Scripts

This directory contains scripts for the paper's RQ3 root-cause and alignment analysis.

## Environment Attribution Judge

`rq3_env.py` classifies how an agent attributes TLS or network failures in an execution trace. It supports the environmental-misattribution analysis.

Output fields:

- `env_attribution`: one of `none`, `mitm_risk`, `test_environment`, `local_proxy`, `corporate_firewall_or_dpi`, or `other`.
- `attribution_present`: whether the agent made a concrete environmental inference.
- `brief_evidence`: concise English evidence from the trace.

Run on a directory of traces:

```bash
python analysis/rq3/rq3_env.py \
  --input artifacts/code_agent_logs/raw/protocol_mismatch \
  --output-dir artifacts/aggregate_results/rq3/environment_attribution \
  --judge-model gpt-5.4-nano \
  --max-workers 4
```

Run from a sampled CSV:

```bash
python analysis/rq3/rq3_env.py \
  --input-csv artifacts/aggregate_results/rq3/sampled_trace_index.csv \
  --output-dir artifacts/aggregate_results/rq3/environment_attribution
```

## Observer Judge

`rq3_observer.py` implements the observer-side security assessment used for actor-observer divergence analysis. It asks an LLM judge to evaluate an existing agent trace as an external security auditor.

Output fields:

- `sas_score`: Security Assessment Score from 1 to 5.
- `endorsement`: whether the observer would approve delivering the final behavior, encoded as 0 or 1.
- `brief_reason`: concise English rationale.

Run on a directory of traces:

```bash
python analysis/rq3/rq3_observer.py \
  --input artifacts/code_agent_logs/raw/self_signed \
  --output-dir artifacts/aggregate_results/rq3/observer_scores \
  --judge-model gpt-5.4-nano \
  --max-workers 4
```

Run from a CSV list:

```bash
python analysis/rq3/rq3_observer.py \
  --input-csv artifacts/aggregate_results/rq3/sampled_trace_index.csv \
  --output-dir artifacts/aggregate_results/rq3/observer_scores
```

The CSV should include a `path` column. If no header is present, the first column is treated as the trace path.

Dry run:

```bash
python analysis/rq3/rq3_observer.py \
  --input artifacts/hitl_logs/raw/self_signed \
  --limit 1 \
  --dry-run
```

The scripts use the OpenAI Python SDK with an OpenAI-compatible endpoint. Configure credentials with `OPENAI_API_KEY` and optionally `OPENAI_BASE_URL`.

## Capability Correlation

The paper's capability-vs-ASR analysis uses public model capability data. That external dataset is not generated by this artifact and is therefore not reproduced here as an experiment script.
