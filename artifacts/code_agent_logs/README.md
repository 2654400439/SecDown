# Code Agent Logs

This directory is the local output placeholder for Aider-based Code Agent runs generated by `agents/code/code_runner.py` and evaluated by `agents/code/code_judge.py`.

Released Code Agent logs and coverage metadata are available through Zenodo:

```text
https://zenodo.org/records/20115421
https://doi.org/10.5281/zenodo.20115421
```

Expected local layout:

```text
code_agent_logs/
  raw/
    self_signed/
    local_issuer/
    hostname_mismatch/
    protocol_mismatch/
  judge_outputs/
  coverage/
```

The paper uses Code Agent logs for RQ1 under self-signed friction and for RQ2 across all four friction profiles.
