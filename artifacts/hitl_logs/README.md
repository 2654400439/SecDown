# HITL Logs

This directory is the local output placeholder for Human-in-the-Loop Agent runs generated by `agents/hitl/hitl_runner.py` and evaluated by `agents/hitl/hitl_judge.py`.

Released HITL logs and coverage metadata are available through Zenodo:

```text
https://zenodo.org/records/20115421
https://doi.org/10.5281/zenodo.20115421
```

Expected local layout:

```text
hitl_logs/
  raw/
    self_signed/
    local_issuer/
    hostname_mismatch/
    protocol_mismatch/
  judge_outputs/
  coverage/
```

For the paper's main RQ1 logic, HITL contributes the self-signed friction measurements. Other HITL friction logs in the Zenodo package are supplemental.
