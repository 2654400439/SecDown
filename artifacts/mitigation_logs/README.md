# Mitigation Logs

This directory is reserved for mitigation experiment outputs generated by `agents/code/code_runner.py`.

Recommended commands:

```bash
python agents/code/code_runner.py --mitigation l1-generic --output-dir artifacts/mitigation_logs
python agents/code/code_runner.py --mitigation l1-targeted --output-dir artifacts/mitigation_logs
python agents/code/code_runner.py --mitigation l2-ast --output-dir artifacts/mitigation_logs
```

Expected layout:

```text
mitigation_logs/
+-- raw/
|   +-- <friction>/
|       +-- <mitigation>/
|           +-- <run_id>/
+-- summary.jsonl
+-- README.md
```

L1 and L2 are Code Agent mitigation runs. L3 is documented in `mitigations/L3_EGRESS_POLICY.md` because it is enforced by network infrastructure rather than this Python runner.
