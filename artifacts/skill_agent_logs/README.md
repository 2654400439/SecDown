# Skill Agent Logs

This directory is the local output placeholder for OpenClaw Skill Agent runs generated by `agents/skill/skill_runner.py`.

Released Skill Agent logs and coverage metadata are available through Zenodo:

```text
https://zenodo.org/records/20115421
https://doi.org/10.5281/zenodo.20115421
```

Expected local layout:

```text
skill_agent_logs/
  raw/
    self_signed/
  judge_outputs/
  coverage/
```

The paper uses Skill Agent logs for the RQ1 self-signed friction comparison. The runner records OpenClaw session traces when available and stores final TUI screen captures for debugging.
